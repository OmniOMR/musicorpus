# MusiCorpus Test Fixture

A tiny synthetic dataset used by this repository's tests. It is not real
data — the images are blank rectangles and the transcriptions hold a
single whole note — but its structure is exactly what the MusiCorpus
specification asks for, so it doubles as a worked example of the layout.

It is generated by `tests/data/build_test_fixture.py`.


## Splits

`splits.json` is a plain train/validation/test division. It deliberately
does not cover every page: `page-outside-splits` is in no split, which
the specification permits. `splits.alternative.json` covers the same
pages differently and adds a `holdout` set.
